Data types in javascript:

JavaScript has several data types, and they can be broadly categorized into two groups: primitive and non-primitive (objects).

Data Type Example Code Description
String let name = "John"; Textual data
Number let age = 25; Numbers (integers and floats)
Boolean let isLoggedIn = true; True or false values
Undefined let x; Variable declared but not initialized
Null let y = null; Intentionally empty value
Symbol let sym = Symbol('id'); Unique and immutable value
BigInt let big = BigInt(12345678901234567890n); Large integer values
Object let obj = {name: "Alice", age: 30}; Collection of key-value pairs
Array let arr = [1, 2, 3]; Ordered list of values
Function function greet() { return "Hello!"; } Reusable code block or object
